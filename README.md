# Web Lab

> **Experiments and archives for web development projects (Frontend, Backend, and Integrated).**

## Repository Structure

* **frontend/** : Client-side projects developed with React, focusing on UI/UX and state management.
  * **[ecomm-ui](./frontend/modern-api-dev-with-spring/ecomm-ui)/** : React e-commerce storefront UI from the *Modern API Development with Spring* book, covering auth, cart, and order/product browsing against the Spring Boot backend.
* **backend/** : Server-side logic and API development using Spring Boot, Ktor, and Kotlin/Java-based architectures.
  * **[kotlin-spring-api-practice](./backend/courses/inflearn/kotlin-spring-api-practice)/** : Kotlin/Spring Boot REST API practice project integrating the Kakao Blog Search API.
  * **[kotlin-spring-security-practice](./backend/courses/inflearn/kotlin-spring-security-practice)/** : Kotlin/Spring Security practice project covering JWT-based authentication and authorization.
  * **[ktor-todo-api](./backend/personal/ktor)/** : Minimal Ktor Todo CRUD API practice project with in-memory storage and auto-generated OpenAPI/Swagger documentation.
  * **[aircraft-positions](./backend/books/spring-boot-up-and-running/aircraft-positions)/** : Spring Cloud Stream consumer from the *Spring Boot: Up and Running* book, ingesting aircraft position messages via RabbitMQ/Kafka and broadcasting them over WebSocket.
  * **[plane-finder](./backend/books/spring-boot-up-and-running/plane-finder)/** : Spring Boot RSocket/REST service from the *Spring Boot: Up and Running* book, publishing generated aircraft positions to RabbitMQ/Kafka via Spring Cloud Stream's StreamBridge.
* **integrated/** : Full-stack applications combining React frontend and Spring Boot backend systems.
  * **[full-stack-react-spring-boot](./integrated/courses/udemy/full-stack-react-spring-boot)/** : Full-stack e-commerce application built across a 21-section React and Spring Boot course.
